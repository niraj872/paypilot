# 3-Minute Demo Script

## 0:00–0:20 — Problem

“AI can recommend things, but it usually cannot safely complete the transaction. What happens when an AI agent wants to spend money?”

## 0:20–0:45 — Intent

Enter:

> Fix my React authentication bug within 24 hours. Maximum $100. Pay only after verification.

Show the structured intent.

## 0:45–1:15 — Negotiation

Show Buyer Agent vs Seller Agent negotiating from an offer above/below target until the final price is within the hard budget.

## 1:15–1:35 — Risk

Show Risk Guardian 8/100 LOW and the backend Policy Engine decision.

## 1:35–1:55 — PayPal

In sandbox mode, show the PayPal order state. In live sandbox mode, show the real approval URL / authorization flow.

## 1:55–2:20 — Verification

Show 96% verification with tests/requirements/deadline checks.

## 2:20–2:40 — Capture + ledger

Show the PayPal capture status and the AG Grid transaction ledger.

## 2:40–3:00 — Failure

Trigger the $150 vs $100 budget case or the verification failure.

End with:

> “AI gets autonomy. Humans keep control. PayPal moves the money.”

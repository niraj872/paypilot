# Sponsor Integration Map

## PayPal — Core
Real production-capable payment integration using the PayPal Orders API and webhooks. Demo mode remains clearly labeled and deterministic.

## AG Grid / AG Studio — Core Analytics
AG Grid powers the transaction intelligence table. AG Studio is embedded over the transaction dataset for interactive dashboard building. A future/optional Studio Agent Framework adapter can be enabled after the team's AG Studio trial/licence setup; no private credentials are committed here.

## Render — Deployment
`render.yaml` provisions the API, frontend and managed PostgreSQL.

## APIMatic — Development Aid
The PayPal service layer is documented against the current PayPal Orders API. When using the APIMatic Context Plugin in the developer's AI coding environment, keep the plugin usage documented in the final Devpost submission only if it was actually used during development.

## Bryntum — Optional Extension
A future enhancement can visualize the task lifecycle as a Gantt/Scheduler timeline. It is intentionally not a dependency of the core flow so that the main demo remains stable.

## Channel3 — Optional Product Mode
A product-search mode can be added only if the Channel3 API/MCP is actually called and used in the product flow. The core service-hiring scenario does not depend on it.
